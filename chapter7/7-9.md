```c
/* foo6.c */
void p2(void);

int main()
{
    p2();
    return 0;
}

/* bar6.c */
#include <stdio.h>

char main;

void p2()
{
    printf("0x%x\n", main);
}
```
**English:** `gcc -Wall -Og -o foobar6 foo6.c bar6.c` compiles and runs, producing `0x48`.

**简体中文：** gcc -Wall -Og -o foobar6 foo6.c bar6.c 编译运行结果：0x48<br/>

**English:** At compile time, `char main` in the `bar6.c` module is a weak symbol, so it is assigned the address of the `main` symbol (a strong symbol) from the `foo6.c` module.

**简体中文：** 因为编译的时候，bar6.c模块里char main是弱符号，所以会分配foo6.c模块的main符号（强符号）的地址<br/>

**English:** `objdump -dx foobar6` disassembles the `main` function:

**简体中文：** objdump -dx foobar6 反汇编查看main函数：<br/>

```
0000000000400520 <main>:
  400520:	48 83 ec 08          	sub    $0x8,%rsp
  400524:	e8 0b 00 00 00       	callq  400534 <p2>
  400529:	b8 00 00 00 00       	mov    $0x0,%eax
  40052e:	48 83 c4 08          	add    $0x8,%rsp
  400532:	c3                   	retq
  400533:	90                   	nop
```
**English:** In fact, `printf("0x%x\n", main)` is equivalent to `printf("0x%x\n", *((char *)main))`.

**简体中文：** 其实printf("0x%x\n", main)就相当于printf("0x%x\n", *(（char *）main))<br/>

**English:** So it prints the first byte at address `400520`, which is `0x48`.

**简体中文：** 所以会输出400520地址的第一个字节也就是0x48<br/>

**简体中文：** 如果bar6.c改为：

unsigned int main;
