```c
/* foo5.c */
#include <stdio.h>
void f(void);

int y = 15212;
int x = 15213;

int main()
{
  f();
  printf("x = 0x%x y = 0x%x \n", x, y);
  return 0;
}

/* bar5.c */
double x;
void f()
{
  x = -0.0;
}
```
**English:** `gcc -Wall -Og -o foobar5 foo5.c bar5.c` <br/>
On my machine, compiling and running also reports this error: <br/>
`/usr/bin/ld: Warning: alignment 4 of symbol 'x' in /tmp/ccP8A6R7.o is smaller than 8 in /tmp/ccq0ZxN6.o` <br/>
The fix is to make `x` in `bar5.c` a static local variable, so the compiler does not place the `x` from the `bar5` module into the COMMON section and allocate the strong-symbol `x` from the `foo5` module; <br/>
instead it places `x` in the `.bss` section.

**简体中文：** gcc -Wall -Og -o foobar5 foo5.c bar5.c <br/>
在我的机器上编译运行也会报这个错：<br/>

而是把x分配到.bss节中
```c
static double x;
void f()
{
  x = -0.0;
}
```
