**English:** A total of `0x230`; the first `0x228` bytes come from the executable's sections, and the remaining space is allocated to the `.bss` section, <br/>
because `.bss` is not allocated memory at compile/link time — it is only allocated memory at run time.

**简体中文：** 总共0x230，开始的0x228字节来自于可执行文件的节，剩余的空间分配被.bss节<br/>
因为.bss在编译链接时不分配内存，只在运行时分配内存。
