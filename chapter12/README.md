## Overview / 概览

**English:** Chapter 12 covers concurrent programming — process-based and thread-based concurrency, semaphores and locks, and classic synchronization problems (producers–consumers, readers–writers). Solutions are analytical Markdown notes, many containing inline C with Pthreads.

**简体中文：** 第 12 章讲解并发编程——基于进程与线程的并发、信号量与锁，以及经典同步问题（生产者–消费者、读者–写者）。全部为分析性 Markdown 笔记，多数内含 Pthreads 的 C 代码。
