**English:** First, lay out a table to find the pattern:<br>

**简体中文：** 首先列一个表格来寻找思路：<br>
|0|1|2|3|...|M|
| -- | -- | -- | -- | -- | -- |
|(0,0)|(0,1)|(0,2)|(0,3)|...|(0,M)|
|(1,0)|(1,1)|(1,2)|(1,3)|...|(1,M)|
|(2,0)|(2,1)|(2,2)|(2,3)|...|(2,M)|
|(3,0)|(3,1)|(3,2)|(3,3)|...|(3,M)|
|...|...|...|...|...|...|
|(M,0)|(M,1)|(M,2)|(M,3)|...|(M,M)|


**English:** The first inner-loop iteration runs once, swapping (1,0) and (0,1).<br>
The second inner-loop iteration runs twice, swapping (2,0) and (0,2), then (2,1) and (1,2).<br>
The third inner-loop iteration runs three times, swapping (3,0) and (0,3), (3,1) and (1,3), (3,2) and (2,3).<br>
Notice that the memory addresses from (M,0) to (M,1) to (M,2) only need to increase by a fixed length; similarly, from (0,M) to (1,M) to (2,M) also increases by a fixed length.<br>
We know the array memory-address formula &A[i][j] = A + 8*(M*i + j).<br>
When the row i is fixed, accessing each column only requires adding 8 to the previous column's address.<br>
When the column j is fixed, accessing each row of that column only requires adding 8*M to the previous row's address.<br>
From the assembly `addq $8 %rdx`, we know %rdx holds &A[i][j].<br>
And from `addq $120 %rax`, we know %rax holds &A[j][i], where 120 = 8*M, so M = 15.<br>

**简体中文：** 第一轮内层循环1次，要交换的是（1，0）和（0，1）<br>
第二轮内层循环2次，要交换的是（2，0）和（0，2）、（2，1）和（1，2）<br>
第三轮内层循环3次，要交换的是（3，0）和（0，3）、（3，1）和（1，3）、（3，2）和（2，3）<br>
发现其中从（M，0）到（M，1）到（M，2）的内存地址只需要加一个固定的长度就可以，同理从（0，M）到（1，M）到（2，M）也是加一个固定长度<br>
我们知道数组访问内存地址公式&A[i][j] = A+8\*(M\*i+j)<br>
当行数i固定时，访问每一列，只需要在前一列的基础上加8就可以<br>
当列数j固定时，访问该列每一行，只需要在前一行的基础上加8\*M就可以<br>
从汇编代码addq $8 %rdx可知%rdx就是&A[i][j]<br>
而addq $120 %rax可知%rax就是&A[j][i]，其中120=8\*M，所以M=15<br>
