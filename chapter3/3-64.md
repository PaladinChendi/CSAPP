**English:** A. Extend Equation 3.1 from two dimensions to three dimensions.

**简体中文：** A.将等式3.1从二维扩展到三维

**English:** The content of Equation 3.1 is:

**简体中文：** 等式3.1的内容是

**English:** For an array `T D[R][C]`, where T is the data type:

`&D[i][j] = xd + L(C*i + j)`, where xd is the array's start address and L is the size of type T in bytes.

**简体中文：** 对于一个数组：T D[R][C] 其中T是数据类型

有：&D[i][j] = xd + L(C*i + j) 其中xd是数组起始地址，L是类型T的长度，单位是字节

**English:** Extending to three dimensions:

**简体中文：** 那么扩展到三维之后是：

**English:** Array: `T A[R][S][T]`

`&A[i][j][k] = xa + L(S*T*i + T*j + k)`, where xa is the array's start address and L is the size of type T in bytes.

**简体中文：** 数组：T A[R][S][T]

有：&A[i][j][k] = xa + L(S\*T\*i + T\*j + k) 其中xa是数组起始地址，L是类型T的长度，单位是字节

**English:** Note: How to understand the three-dimensional formula? We can picture it as a cube divided into R layers, each layer containing S*T small blocks.

**简体中文：** 注：怎么理解三维的公式？我们可以把他想象成一个正方体，分成R层，每层有S\*T个小方块

**English:** To find the block &A[i][j][k], first count which layer — that gives S*T*i. Then within layer i, find the block at row j, column k. Each row has T blocks, so that is j*T + k.

**简体中文：** 那么我要找&A[i][j][k]这个方块，先数第几层，就是S\*T\*i，然后在第i层里，找到第j行，第k列的方块，每行有T个方块，那么就是j\*T + k

**English:** B. From the assembly code, determine the values of R, S, and T.

**简体中文：** B.根据汇编代码，确定R、S、T的值

**English:** Reverse-engineered from the assembly code:

`*dest = 65*i + 13*j + k`

`sizeof(A) = 3640`

**简体中文：** 由汇编代码反推出

*dest=65\*i + 13\*j + k

sizeof(A) = 3640

**English:** From the formula in part A we get:

`S*T = 65`

`T = 13`

So:

`S = 5`

**简体中文：** 根据A中的公式可以得出:

S*T=65

T=13

所以

S=5

**English:** And since A occupies R*S*T*8 bytes, and `sizeof(A) = 3640`, we get R = 7.

**简体中文：** 又因为A = R\*S\*T*8个字节

且sizeof(A) = 3640 

所以 R = 7
