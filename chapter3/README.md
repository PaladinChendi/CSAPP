## Overview / 概览

**English:** Chapter 3 covers x86-64 assembly — instruction encoding, registers, arithmetic and control flow, procedure calls and stack discipline, and how arrays, structs, and data structures are laid out in memory. Solutions mix a few C programs with analytical Markdown notes that annotate assembly.

**简体中文：** 第 3 章涵盖 x86-64 汇编——指令编码、寄存器、算术与控制流、过程调用与栈规约，以及数组、结构与数据结构在内存中的布局。解答以少量 C 程序与带汇编注释的分析性 Markdown 笔记混合而成。
