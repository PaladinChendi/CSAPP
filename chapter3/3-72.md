```
--------- s1
|   e1   |
---------- p + n*8
|        |
|        |
|        |
---------- p
|   e2   |
---------- s2
```

**English:** A.<br>
When n is odd, s2 = s1 - (24 + 8*n).<br>
When n is even, s2 = s1 - (16 + 8*n).<br>
The idea is to round down to a multiple of 16.<br>
<br>

**简体中文：** A.<br>
当n为奇数时，s2 = s1 - (24 + 8*n)<br>
当n为偶数时，s2 = s1 - (16 + 8*n)<br>
道理就是要向下取整为16的倍数<br>
<br>

**English:** B.<br>
p = (s2 + 15) & 0xfffffff0, rounding down to a multiple of 16.<br>
<br>

**简体中文：** B.<br>
p = (s2 + 15) & 0xfffffff0，向下取整为16的倍数<br>
<br>

**English:** C.<br>
We can understand it by assigning values to s2:<br>
s2=0, p=0, e2=p-s2=0<br>
s2=1, p=16, e2=p-s2=15<br>
s2=2, p=16, e2=p-s2=14<br>
...<br>
s2=15, p=16, e2=p-s2=1<br>
s2=16, p=16, e2=p-s2=0<br>
<br>
To minimize e1, we must minimize e1+e2 while maximizing e2. When n is even, e1+e2=16 is minimal; when s1%16=1, e2=15 is maximal.<br>
<br>
That is: when n is even and s1%16=1, e1 is minimized.<br>
<br>
To maximize e1, we must maximize e1+e2 while minimizing e2. When n is odd, e1+e2=24 is maximal; when s1%16=0, e2=0 is minimal.<br>
<br>
That is: when n is odd and s1%16=0, e1 is maximized.<br>
<br>

**简体中文：** C.<br>
可以通过给s2赋值来理解：<br>
s2=0,p=0, e2=p-s2=0<br>
s2=1,p=16,e2=p-s2=15<br>
s2=2,p=16,e2=p-s2=14<br>
...<br>
s2=15,p=16,e2=p-s2=1<br>
s2=16,p=16,e2=p-s2=0<br>
<br>
要使e1的值最小，则需使e1+e2最小同时e2最大。当n为偶数时，e1+e2=16最小；当s1%16=1时，e2=15最大。<br>
<br>
即：n为偶数，s1%16=1时e1最小。<br>
<br>
要使e1的值最大，则需使e1+e2最大同时e2最小。当n为奇数时，e1+e2=24最大；当s1%16=0时，e2=0最小。<br>
<br>
即：n为奇数，s1%16=0时e1最大。<br>
<br>
