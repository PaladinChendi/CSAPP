## Overview / 概览

**English:** Chapter 8 covers exceptional control flow — exceptions and interrupts, process creation with `fork`, program loading with `execve`, signal handling, and writing a simple shell. Solutions are analytical Markdown notes, several containing inline C code.

**简体中文：** 第 8 章讲解异常控制流——异常与中断、用 `fork` 创建进程、用 `execve` 载入程序、信号处理，以及编写简易 shell。全部为分析性 Markdown 笔记，部分笔记内含 C 代码。
