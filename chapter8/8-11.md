```c
/* $begin forkprob1 */
#include "csapp.h"

int main() 
{
    int i;

    for (i = 0; i < 2; i++) 
	    Fork();
    printf("hello\n");
    exit(0);
}
/* $end forkprob1 */
```
**English:** Process diagram:

**简体中文：** 进程图：
```
main---->fork---->fork---->printf---->exit
           |        |
           |        ---->printf---->exit
           |
            ---->fork---->printf---->exit
                   |
                   ---->printf---->exit
```
**English:** Four "hello"s are printed (note that the parent process forks once when the loop counter i=0, and once again when i=1).

**简体中文：** 输出四个hello（注意父进程循环i=0时fork一次，i=1时fork一次）
