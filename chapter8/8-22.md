```c
#include <stdio.h>
#include <errno.h>
int main(int argc, char* argv[], char* env[]) {
  if (execve("/bin/ls", argv, env) == -1) {
    fprintf(stderr, "execve error: %s\n", strerror(errno));
    exit(1);
  }
}
```
**English:** The error is that 5 signals are sent at the same time, but only the first is received; the rest become pending signals, and a pending signal can only be received once.

**简体中文：** 错误再于同时发送5个信号，只有第一个会被接收，其他都是待处理信号，而待处理信号只能被接收一次。
