```c
/* $begin forkprob3 */
#include "csapp.h"

int main() 
{
    int x = 3;

    if (Fork() != 0)
	    printf("x=%d\n", ++x);

    printf("x=%d\n", --x);
    exit(0);
}
/* $end forkprob3 */
```
**English:** Process diagram:

**简体中文：** 进程图：
```
main---->fork---->printf---->printf---->exit
          |
           ---->printf---->exit
```
**English:** Both the parent and the child start with x=3; the concurrent execution yields three possible orderings:<br/>
2 4 3, 4 2 3, and 4 3 2.

**简体中文：** 父进程和子进程x的初始值都是3,并发有三种组合：<br/>
2 4 3、 4 2 3 和 4 3 2
