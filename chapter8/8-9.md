| AB / AB              | No / 否                        |
| AC / AC              | Yes / 是                       |
| AD / AD              | Yes / 是                       |
| BC / BC              | Yes / 是                       |
| BD / BD              | Yes / 是                       |
| CD / CD              | Yes / 是                       |
