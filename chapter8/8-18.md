```c
/* $begin forkprob2 */
#include "csapp.h"

void end(void) 
{
    printf("2"); fflush(stdout);
}

int main() 
{
    if (Fork() == 0) 
	    atexit(end);
    if (Fork() == 0) {
	    printf("0"); fflush(stdout); 
    }
    else {
        printf("1"); fflush(stdout); 
    }
    exit(0);
}
/* $end forkprob2 */

```
进程图：
```
main---->fork---->fork---->printf:1---->exit
           |       |
           |       ---->printf:0---->exit
           |
           ---->fork---->printf:1---->printf:2---->exit
                 |
                 ---->printf:0---->printf:2---->exit
```
**English:** The permutations must satisfy: one `2` is preceded by a `1`, and the other `2` is preceded by a `0`, so the answers are C and E.

**简体中文：** 排列组合结果必须满足一个2的前面有个1，另外一个2的前面有个0，所以是C和E
