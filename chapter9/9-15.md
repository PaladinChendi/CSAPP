The table below shows, for each request, the block size in decimal bytes and the block header in hexadecimal.

| Request | Block size (decimal bytes) | Block header (hex) |
| ---------- | -------------------- | ------------------ |
| malloc(3)  | 8 Bytes               | 0x00000009         |
| malloc(11) | 16 Bytes              | 0x00000011         |
| malloc(20) | 24 Bytes              | 0x00000019         |
| malloc(21) | 32 Bytes              | 0x00000021         |

**简体中文：**
| 请求       | 块大小（十进制字节） | 块头部（十六进制） |
| ---------- | -------------------- | ------------------ |
| malloc(3)  | 8Bytes               | 0x00000009         |
| malloc(11) | 16Bytes              | 0x00000011         |
| malloc(20) | 24Bytes              | 0x00000019         |
| malloc(21) | 32Bytes              | 0x00000021         |


**English:** The point to note is double-word alignment: while ensuring the block size is a multiple of 8 bytes, you must also account for the 4 bytes occupied by the block header.

**简体中文：** 注意的地方就是双字对齐，考虑块大小是8字节的倍数的同时也要考虑块头部要占4字节
