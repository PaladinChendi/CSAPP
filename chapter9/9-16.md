**English:** The minimum block size under different alignment requirements and whether allocated/free blocks carry a header and/or footer.

**简体中文：** 不同对齐要求下、以及已分配块/空闲块是否带头部和/或脚部时的最小块大小。

| Alignment / 对齐要求 | Allocated block / 已分配块 | Free block / 空闲块 | Minimum block size (bytes) / 最小块大小（字节） |
| -------- | ------------------ | ---------- | ------------------ |
| Single word / 单字 | Header and footer / 头部和脚部 | Header and footer / 头部和脚部 | 16 |
| Single word / 单字 | Header, but no footer / 头部，但是没有脚部 | Header and footer / 头部和脚部 | 16 |
| Double word / 双字 | Header and footer / 头部和脚部 | Header and footer / 头部和脚部 | 16 |
| Double word / 双字 | Header, but no footer / 头部，但是没有脚部 | Header and footer / 头部和脚部 | 16 |


**English:** Because free blocks all contain a 4-byte header and footer, plus 4-byte predecessor (pred) and successor (succ) pointers, the minimum free block size is always 16 bytes.
The minimum block size = max(minimum allocated block size, minimum free block size).
This is because if you took the smaller of the two — for example, in the first row the minimum allocated block is 12 bytes — then if that 12-byte allocated block were freed, it could not be inserted into the free list, since the minimum free block is 16 bytes.

**简体中文：** 因为空闲块都包含4字节的头部和脚部，并且还有4字节的前驱pred和后继succ指针，所以最小空闲块大小都是16字节
最小块大小 = max(最小已分配块大小，最小空闲块大小)
因为如果取二者的最小值，比如第一行，最小已分配块是12字节，如果这个12字节的已分配块释放了，那么他就无法加入到空闲链表，因为最小空闲块是16字节
