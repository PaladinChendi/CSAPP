**English:** This problem assumes a fixed number of bits per track, so the total capacity simplifies to: bits per track × number of tracks × surfaces per platter × number of platters. With surfaces per platter and number of platters held constant (a constant K), capacity is determined by "bits per track × number of tracks". Bits per track is proportional to circumference: assume `xr * M` (M constant). Number of tracks is proportional to `r - xr`: assume `(r - xr) * N` (N constant). The final capacity is `xr * M * (r - xr) * N * K`, i.e. we need to maximize `-x^2 + x`, giving `x = 0.5`.

**简体中文：** 这道题假设每条磁道位数固定，那么计算总容量就可以简化为：磁道位数X磁道数X每个盘片盘面数X盘片数<br/>

每个盘片盘面数和盘片数假设不变，为常数K，那么容量就是由「磁道位数X磁道数」决定的<br/>

磁道位数和周长成正比，假设为：xr * M，M为常数<br/>
磁道数和r-xr成正比，假设为(r-xr) * N，N为常数<br/>
最终容量为xr * M * (r-xr) * N * K，即需要-x^2 + x最大，得到x = 0.5。<br/>
