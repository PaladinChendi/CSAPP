## Overview / 概览

**English:** Chapter 6 covers the memory hierarchy and cache memory — cache organization (direct-mapped, set-associative), hit/miss analysis, the impact of memory access patterns, and cache blocking. All solutions are analytical Markdown notes.

**简体中文：** 第 6 章讲解存储器层次结构与缓存——缓存组织（直接映射、组相联）、命中/缺失分析、内存访问模式的影响以及缓存分块。全部为分析性 Markdown 笔记。
