# Chapter 2 — Representing and Manipulating Information / 信息的表示与处理

> ← [README (English)](../README.md) · [README（简体中文）](../README.zh-CN.md)

## Overview / 概览

**English:** Chapter 2 covers how computers represent and manipulate information — two's-complement integer arithmetic, bitwise operations, and floating-point representation. The homework here is dominated by standalone C "bit puzzle" programs, plus a handful of analytical Markdown notes on floating-point values.

**简体中文：** 第 2 章讨论计算机如何表示与处理信息——补码整数运算、位运算与浮点表示。本章习题以自包含的 C "位谜题"程序为主，辅以若干关于浮点数值的分析性 Markdown 笔记。
