# Chapter 4 — Processor Architecture (Y86-64) / 处理器体系结构（Y86-64）

> ← [README (English)](../README.md) · [README（简体中文）](../README.zh-CN.md)

## Overview / 概览

**English:** Chapter 4 builds a simplified Y86-64 instruction set and implements it first as a sequential processor, then as a pipelined one. The homework is entirely analytical — Markdown notes covering instruction semantics, pipeline staging, hazard handling, and cycle-by-cycle traces. Several notes are lengthy (pipeline traces for 4-54 through 4-58).

**简体中文：** 第 4 章构建简化的 Y86-64 指令集，并先以顺序处理器、再以流水线处理器实现。本章习题全部为分析题——Markdown 笔记涵盖指令语义、流水线分段、冒险处理与逐周期跟踪。其中 4-54 至 4-58 的流水线跟踪篇幅较长。
